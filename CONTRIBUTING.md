# Contributing

Contributions should improve the reproducibility and fairness of the pricing experiment.

## Guidelines

- Read the README, challenge problem statement, and data documentation first.
- Never use external price lookup, scraped prices, private labels, or prohibited data augmentation.
- Keep raw datasets immutable and put generated images, caches, checkpoints, and predictions in ignored directories.
- Record seeds, package versions, feature engineering, validation split, and metric calculations.
- Check model and pretrained-model licenses and parameter limits before adding them.

## Pull requests

Describe the model or documentation change, data sources, validation method, SMAPE result, and resource requirements. Include a small reproducible command and confirm that no restricted information or generated artifacts were added.
