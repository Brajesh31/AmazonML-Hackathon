# 🌍 Code of Conduct

## Our commitment
We aim to make this project a respectful, inclusive, constructive, and technically honest collaboration space.

## Expected behavior
- Be respectful and assume good intent.
- Give actionable, evidence-based feedback.
- Welcome different experience levels and perspectives.
- Credit work accurately.
- Respect dataset terms, model licenses, and competition rules.
- Report bugs and security issues responsibly.

## Unacceptable behavior
Harassment, discrimination, threats, personal attacks, doxxing, plagiarism, deliberate misinformation, credential exposure, and attempts to evade challenge restrictions are not acceptable.

## Enforcement
Project conduct concerns can be reported privately to the repository owner, Brajesh Kumar, through the GitHub profile [@Brajesh31](https://github.com/Brajesh31). Reports will be reviewed and handled at the maintainers' discretion. Do not include passwords, access tokens, or private dataset contents in a report.
